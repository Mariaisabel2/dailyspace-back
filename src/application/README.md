# Capa de Aplicación (Application Layer)

Orquesta los flujos de datos y casos de uso del sistema:
- **Casos de Uso de Autenticación:** `RegisterUserUseCase`, `LoginUserUseCase`.
- **Casos de Uso del Catálogo:** `GetPostsUseCase`, `GetPostByIdUseCase`, `CreatePostUseCase`, `UpdatePostUseCase`, `DeletePostUseCase`.
- **Casos de Uso de Interacciones:** `CreateCommentUseCase`, `GetMyCommentsUseCase`, `GetAllCommentsUseCase`, `DeleteCommentUseCase`.
- **Servicios:** Tokens JWT y funciones de seguridad.
